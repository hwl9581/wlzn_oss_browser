# 1.0.1 验证记录

日期：2026-10-28。环境仍为本机 IntelliJ IDEA 2026.1.2，`IU-261.24374.151`。

本轮修复用户反馈的配置、上传问题，并复用已有图标：

- Region 和 Endpoint 可留空；Endpoint 空时，同一账号按 Bucket 的实际区域路由浏览、传输、续传、分片清理及预签名。Region 只作为初始区域，实际发现结果不回写账号配置，不修改旧断点身份。
- 显式 Endpoint 保留手动模式；自动连接创建 Bucket 时单独选择 Region。跨区域复制在写入前拒绝。区域提示按连接/修订/账号指纹隔离，重新连接刷新缓存；OSS 不自动跟随任意 HTTP 重定向。
- 真实平台按钮回归覆盖首次空表单点击 OK→校验失败→补齐名称和密钥→OK 恢复并提交；缺失密钥仍阻断保存。修复配置表单及目标目录表单的持续校验。
- 已在修复前用官方 OSS SDK + 本机 HTTP 服务复现上传 NPE：`IsTruncated=false` 时，响应可以省略 `NextPartNumberMarker`，原代码把 nullable Integer 拆箱成 Int。原始失败为 `getNextPartNumberMarker(...) must not be null`，位于 `AliyunStorageClient.parts`。
- OSS/S3 现在只有下一页存在时才读取并校验游标。空列表正常返回；异常缺失/不前进的下一页游标明确报错，避免空指针或无限分页。新增从新文件开始的完整 SDK 上传流程测试。
- 上传读取本地文件大小后立即上报 total，初始化期间也能看到实际文件大小。意外异常记录类型和栈帧，不记录原始异常消息中的密钥、Token、URL；日志标识为 `WLZN OSS transfer`。
- `META-INF/pluginIcon.svg` 与 Nacos/Torna 原固定图标逐字节一致；工具窗口仅缩放同一图案至 16px，没有重新设计图案。另两个项目无改动。
